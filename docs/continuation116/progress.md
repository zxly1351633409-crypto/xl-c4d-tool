# C4D 风格节点迁移进度

更新日期：2026-11-05。本文是本地审计记录的筛选摘要；完整原始报告和测试数据未随本文件公开，因此它不是完整可复跑证据。

原正式目录的 **116 个公开根**已在目录对账中全部保留。当前隔离候选目录为 **118 行**，新增人形素体与贝塞尔曲面；节点库有 **521 组**，其中包含私有组和旧组。Source48 研究预览已公开；本机没有安装替换，正式版本仍为 3.5.115。

截至该检查点，累计 410 次成功 Blender actor、94 次原生动作和 46 次失败 actor；这些是运行次数，不是功能数或覆盖率。

## 已有的受限证据

- 参数体有多个固定参数与方向样例；部分切片只在明确条件下启用。
- 旋转、扫描与放样分别有特定轮廓、路径、分段或网格样例的验证。
- 斜切、扭曲与锥化有指定参数、控制框和普通入口样例的验证。最新锥化真 None 控制对象、限制模式、关闭圆角且曲率 0.37 的样例已经通过；结论仍只覆盖记录的参数和几何。

以上均不代表对应功能的所有参数或一般情形已经通过。

## 未结难点

油罐与胶囊部分切面三角化仍缺已验证的一般规则；闭合贝塞尔控制网、人形分段和地形噪声缺可追溯机制。锥化负曲率存在写入意图与实际读回不一致，也不能据此称负曲率通过。

原始 116 根目录分母已确认，但还没有统一的逐根、逐语义完成标准和验收表，**无法诚实计算功能完成百分比或总体工期**。建立矩阵并取得真实未结范围和运行耗时后，再校准阶段时间。

## 下一阶段与加速

先建立逐根、逐语义验收矩阵，记录已通过范围、对应证据、未结项和未知项，再按真实失败、用户价值与机制可追溯性排序。只读溯源、数学预测、机械比对和证据整理可在互斥责任下并行；Blender、C4D、GUI 和大型 I/O 保持资源检查与单槽串行。

按功能语义批次复用已有证据并统一验收差异，减少每个样例重复完整 canonical 流程和频繁小停顿。失败时保留原始值并定位原因，不以盲目采样、拟合或降低阈值充当进度。候选保存、独立 fresh、普通入口和最终发布体验分别记录。
