# xl_c4d_tool 3.4.0

面向 Blender 5.1 的 C4D 风格工作流工具集，把常用生成器、变形器、MoGraph 类节点、重拓扑、节点浏览和材质辅助集中到一套中文界面中。

> 当前目录是开发母版，不等同于可直接公开的发布包。公开发布前必须按“开源与分发边界”执行许可和外部依赖清理。

## 功能入口

- `3D 视图 > N > c4d小工具 > 修改器库`：选择网格对象，搜索并添加项目几何节点修改器。
- `3D 视图 > N > c4d小工具 > C4D工具`：场景整理、样条提取、物体/原点对齐等辅助工具。
- `3D 视图 > N > c4d小工具 > C4D工具 > 四边重拓扑…`：打开四边重拓扑设置并确认执行。
- `几何节点编辑器 > N > c4d小工具`：按 C4D 风格分类、搜索并放置项目节点组。
- `着色器节点编辑器 > N > c4d小工具`：材质节点助手与 Node Preview 节点缩略图。
- `编辑 > 偏好设置 > 插件 > xl_c4d_tool`：节点浏览器、面板布局、列数和节点预览设置。

## 安装

1. 使用 Blender 5.1。
2. 将发布 ZIP 作为整体安装：`编辑 > 偏好设置 > 扩展/插件 > 从磁盘安装`，不要把 ZIP 内文件单独拆散。
3. 启用 `xl_c4d_tool`。
4. 在 3D 视图或节点编辑器按 `N`，确认出现 `c4d小工具` 标签页。

升级前请备份正在制作的 `.blend` 文件。若由旧版本升级，先关闭 Blender，再覆盖或重新安装；不要同时保留多个同名插件目录。

## 快速使用

### 添加修改器

1. 选择一个网格对象。
2. 打开 `N > c4d小工具 > 修改器库`。
3. 选择分类或输入关键词。
4. 点击目标功能，插件会在当前文件缺少节点组时从随附资产追加，并给所选对象添加几何节点修改器。

随附资产以 `assets/C4D生成器复刻.blend` 为主。追加节点时保留节点接口标识和已有修改器参数，不在追加过程中重建接口。

### 在几何节点编辑器中放置节点组

打开几何节点编辑器，在 `N > c4d小工具` 中选择节点组。节点会跟随鼠标，左键确认放置；可使用分类、搜索、收藏和最近使用提高查找速度。

### 四边重拓扑

在 3D 视图选择目标网格，打开 `C4D工具 > 四边重拓扑…`，根据模型规模选择质量预设后执行。该模块封装 QRemeshify / QuadWild / QuadPatches；第三方许可见 `重拓扑/THIRD_PARTY_LICENSES.md`。

## 置换 2.0（3.4.0）

`XL_置换` 已从“仅接收浮点高度、默认值会产生零位移”的旧结构升级为图像驱动的非破坏置换。公开接口共 18 个插槽（含几何输出），内部为 32 个节点、45 条连接，并按与项目其他节点一致的 7 段中文语义框组织。

主要输入：

- `图像`：作为高度来源；不指定图像时保持原几何，不发生意外位移。
- `UV 名称`、`优先 UV`：优先使用命名 UV；不可用时可回退到位置坐标。
- `平铺`、`偏移`：调整纹理采样坐标。
- `使用 Alpha`：在灰度高度和 Alpha 高度之间选择。
- `底部级别`、`顶部级别`、`中心`：重映射并确定零位移基准。
- `高度`：总位移强度，安全默认值为 `0.1`。
- `反转`、`选择`：翻转高度或仅作用于选区。
- `细分级别`：置换前增加网格密度；应从低值开始，避免视口卡顿。
- `沿法线`、`方向`：在表面法线与固定方向之间选择。
- `平滑着色`：控制输出网格的平滑显示。

推荐流程：先指定图像和 UV，再把细分保持在低值，确认方向后逐步增加 `高度`。若图像看似没有作用，依次检查对象是否有有效 UV、`选择` 是否为真、`高度` 是否非零，以及黑白级别是否被设成相同值。

结构验证记录：无图像时输出不变；验证图像产生约 `0.437` 的高度范围；测试输出为 `289` 个顶点。该结果用于确认置换链路确实改变了求值几何，不代表所有模型都应得到相同数值。

## 其他工作流说明

### 布尔显示联动

`XL_布尔`、`XL_连接`、`XL_融球` 的操作源被引用时自动显示为线框并显示名称，同时不参与渲染；解除引用或更换目标后恢复原状态。插件不再修改 Cycles 射线可见性，旧版本留下的射线可见性备份会在下次同步时还原并清理。

### 材质云层

`着色器节点编辑器 > N > c4d小工具 > c4d_材质节点助手 > C4D_云层` 可创建用于平面的透明云层材质，提供云疏密、云块大小、过渡、细节、扭曲、颜色、透明度和亮度等参数。

### Node Preview

Node Preview v1.21 已集成到插件偏好设置和着色器节点编辑器，用于显示节点渲染缩略图。其原作者与 GPL 许可完整保留，详见 `THIRD_PARTY_LICENSES.md` 和 `node_preview/LICENSE`。

## 开源与分发边界

公开仓库和发布 ZIP 只能包含作者有权再分发的源码、资产和依赖。当前开发母版中发现或研究过的以下内容不得因“写了署名”就直接进入公开包：

- Geo-Scatter 的 `non_gpl` 引擎或其他禁止再分发/衍生的内容；
- PF Hardshell；
- Advanced Array；
- 来源不明、商业购买或许可无法确认的节点、脚本、纹理、字体、二进制和 `.blend` 资产；
- 指向本机绝对路径或缺失外部库的引用。

Cashew Nodes（Con11，GPL-3.0）仅作为 `XL_置换` / 浮雕工作流的设计研究参考；许可和修改说明见 `THIRD_PARTY_LICENSES.md`。公开发布前仍需以白名单方式重新组装发布包，并对每个随附组件逐项核验。
